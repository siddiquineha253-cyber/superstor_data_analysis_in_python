## Project Overview
This project performs an end-to-end **Exploratory Data Analysis (EDA)** on **345,000+ rows** of Indian Agricultural Crop Production data using Python. It explores state-wise production, crop trends over the years, top-producing crops, and seasonal agricultural patterns in India.

## Key Business & Analytical Questions Solved
1. **Top States:** Which are the top five states by total crop production?
2. **Yearly Trends:** What is the trend of total crop production over the years?
3. **Top Crops:** What are the top ten crops by total production in India?
4. **Seasonal Impact:** What is the crop production distribution across different farming seasons?

## Dataset Overview
- **Total Records:** 345,407 rows and 10 columns
- **Features Included:** State, District, Crop, Year, Season, Area, Area Units, Production, Production Units, Yield.

## Tech Stack & Libraries Used
- **Language:** Python
- **Environment:** VS Code / Jupyter Notebook
- **Libraries:** 
  - `pandas` - Data manipulation & cleaning
  - `numpy` - Numerical calculations
  - `matplotlib.pyplot` & `seaborn` - Data visualization
